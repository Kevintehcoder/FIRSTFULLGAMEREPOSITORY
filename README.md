# FIRSTGAME Code
Code written for my first EVER game in unity, 
a 2D top down dungeon explorer with 2 bosses and 3 enemies.

## Tech Used
* C#
* Unity

## Systems Implemented
* Queues and Dictionaries
* Scene Management
* Fluid StateMachines
* Physics
* Many polymorphism
* Many scriptable objects
* Many helper classes

## New Knowledge gained
* Queues and Dictionaries
* Better StateMachines
* Game Physics
* Useful Polymorphism
* Optimizing CPU
* Better Uis
